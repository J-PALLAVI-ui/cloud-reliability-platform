# Cloud Reliability Engineering Platform

A cloud-native application built using Node.js, Express, Docker, and GitHub.

## Project Overview

This project demonstrates a basic cloud reliability platform where an application is containerized using Docker and prepared for CI/CD automation.

## Technologies Used

- Node.js
- Express.js
- Docker
- Git
- GitHub

## Features

- REST API endpoints
- Health monitoring endpoint
- User API endpoint
- Docker container deployment
